Standard Operating Procedures

SOP-01
RMF Assessment (Step 4 — Assess)
  1. 1.Confirm system boundary, authorization package, and SSP
  2. 2.Run ACAS / Nessus credentialed scan against target systems
  3. 3.Apply applicable DISA STIGs; validate with SCAP benchmarks
  4. 4.Conduct structured fuzzing (Blackduck Defensics) against exposed interfaces
  5. 5.Map findings to NIST 800-53 controls; assess residual risk by mission impact
  6. 6.Populate SAR prioritized by mission impact, not CVSS score alone
  7. 7.Document POA&M entries; advise on risk acceptance vs. remediation tradeoffs
NessusDISA STIGsSCAPDefensicsSAR / POA&M
SOP-02
Full-Scope Penetration Test
  1. 1.Obtain written authorization; define scope and rules of engagement
  2. 2.Passive recon: OSINT, DNS enumeration, Shodan, WHOIS
  3. 3.Active scan: Nmap SYN (-sS -sV -O --top-ports 1000)
  4. 4.Vulnerability identification: Metasploit, searchsploit, Nuclei
  5. 5.Exploitation with minimal footprint; document each step with screenshots
  6. 6.Post-exploitation: credential harvest, lateral movement, persistence
  7. 7.Clean all artifacts; generate CVSS-scored report with remediation priorities
MetasploitNmapKaliPTES
SOP-03
Bug Bounty Recon Workflow
  1. 1.Run Andromalius: crt.sh + subfinder + amass + DNS brute-force
  2. 2.Deduplicate and filter wildcard records from subdomain list
  3. 3.Multi-threaded HTTP/HTTPS live host detection with tech fingerprinting
  4. 4.Run Balam Phase 2: port scan, dir bust, Nuclei, CORS, VCS checks
  5. 5.Grep report for admin/login/dev/staging high-value targets
  6. 6.Manual testing of high-probability findings with documented PoCs
AndromaliusBalamNucleisubfinder
SOP-04
FAIR Quantitative Risk Assessment
  1. 1.Define asset scope, threat communities, and loss scenarios
  2. 2.Estimate TEF, vulnerability, and control strength ranges
  3. 3.Estimate loss magnitude: primary, secondary, SLEF, SLM
  4. 4.Run Monte Carlo simulation in FAIR-U (10K+ iterations)
  5. 5.Compare to benchmarks; surface underestimation gaps
  6. 6.Model control improvements; calculate risk reduction ROI
  7. 7.Present prioritized remediation roadmap to stakeholders
FAIR-UMonte CarloCVSS 3.1
SOP-05
Linux CIS Hardening
  1. 1.Baseline Lynis scan; record initial hardening index
  2. 2.Apply PAM: 14-char min, complexity classes, 90-day rotation
  3. 3.Harden SSH: disable root, MaxAuthTries 4, Protocol 2 only
  4. 4.Configure UFW default-deny; explicit allow rules only
  5. 5.Enable Auditd with rules for privileged command execution
  6. 6.Re-run Lynis; map improvements to CIS benchmark controls
  7. 7.Document delta and remaining gaps with remediation timeline
LynisUFWPAMAuditdCIS
SOP-06
Web App Pentest (OWASP)
  1. 1.Spider target in Burp Suite; map all endpoints and parameters
  2. 2.Directory/file enumeration with Gobuster and API wordlists
  3. 3.Test authentication: default creds, brute-force, token analysis
  4. 4.Test OWASP Top 10: SQLi, XSS, CSRF, IDOR, SSRF, XXE
  5. 5.Check CORS, exposed .git/.env, MIME bypass, upload vulns
  6. 6.Document each finding with CVSS score and reproducible PoC
